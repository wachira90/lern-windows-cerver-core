# Windows Server 2019

## License

การให้สิทธิ์การใช้งาน Windows Server 2019 Standard จะคำนวณตามจำนวนคอร์ของ CPU โดยมีข้อกำหนดว่าต้องซื้อไลเซนส์ขั้นต่ำสำหรับ 16 คอร์ แม้ว่าเซิร์ฟเวอร์ของคุณจะมีเพียง 4 คอร์ก็ตาม

ราคาของไลเซนส์ Windows Server 2019 Standard สำหรับ 16 คอร์ในประเทศไทยมีรายละเอียดดังนี้:

- **ราคาต่อ 2 คอร์**: ประมาณ 3,900 บาท
- **ราคาสำหรับ 16 คอร์ (8 ไลเซนส์)**: 3,900 บาท x 8 = 31,200 บาท

นอกจากนี้ คุณยังต้องซื้อ Client Access License (CAL) เพิ่มเติมสำหรับผู้ใช้หรืออุปกรณ์ที่เข้าถึงเซิร์ฟเวอร์:

- **Device CAL**: ประมาณ 1,100 บาทต่อไลเซนส์
- **User CAL**: ประมาณ 1,300 บาทต่อไลเซนส์

ดังนั้น หากเซิร์ฟเวอร์ของคุณมี CPU 4 คอร์ คุณจะต้องซื้อไลเซนส์ขั้นต่ำสำหรับ 16 คอร์ รวมถึง CAL ตามจำนวนผู้ใช้หรืออุปกรณ์ที่เข้าถึงเซิร์ฟเวอร์ด้วย

โปรดทราบว่าราคาอาจแตกต่างกันไปตามผู้จัดจำหน่ายและโปรโมชั่นในแต่ละช่วงเวลา ควรตรวจสอบราคาล่าสุดจากผู้จัดจำหน่ายที่เชื่อถือได้ในประเทศไทย
